# yamuse

[![crates.io](https://img.shields.io/crates/v/yamuse.svg)](https://crates.io/crates/yamuse)
[![docs.rs](https://img.shields.io/docsrs/yamuse)](https://docs.rs/yamuse)
[![license](https://img.shields.io/crates/l/yamuse.svg)](LICENSE)

*[in english](https://github.com/flxxxxddd/yamuse/blob/main/README.md)*

типизированный асинхронный rust-клиент к api яндекс музыки.

покрывает каталог, библиотеку, радио, поиск, историю прослушиваний, lossless-загрузки
и поток состояния плеера ynison — всю поверхность приватного api, которым пользуются
официальные приложения.

сделан ради неудобной части этого: api недокументирован и меняется без
предупреждения, поэтому каждая модель деградирует вместо того, чтобы падать,
несостоявшаяся мутация — это ошибка, а не `false`, и недописанная загрузка никогда
не попадает на диск.

```toml
[dependencies]
yamuse = "0.3"
tokio = { version = "1", features = ["macros", "rt-multi-thread"] }
```

rust 2024, msrv 1.85. без `chrono`, по умолчанию без `openssl`.

## быстрый старт

```rust,no_run
use yamuse::Client;

#[tokio::main]
async fn main() -> Result<(), yamuse::Error> {
    let client = Client::builder().token(std::env::var("YM_TOKEN").unwrap()).build()?;
    client.init().await?;

    let results = client.search("nine inch nails", Default::default()).await?;
    for track in results.track_results() {
        println!("{} — {}", track.artists_name(), track.title.as_deref().unwrap_or("?"));
    }
    Ok(())
}
```

## аутентификация

публичного api-ключа не существует. аутентификация — это oauth-токен, который
получают через device flow: не нужно ни встраивать браузер, ни трогать пароль.

```rust,no_run
# async fn run() -> Result<(), yamuse::Error> {
let client = yamuse::Client::anonymous()?;

let token = client
    .device_auth(Default::default(), |code| {
        println!(
            "откройте {} и введите {}",
            code.verification_url.as_deref().unwrap_or(""),
            code.user_code.as_deref().unwrap_or(""),
        );
    })
    .await?;

println!("access token: {}", token.access_token.as_deref().unwrap_or(""));
println!("refresh token: {}", token.refresh_token.as_deref().unwrap_or(""));
# Ok(())
# }
```

токены истекают. сохраните refresh-токен и обновляйтесь через
[`refresh_token`](https://docs.rs/yamuse/latest/yamuse/struct.Client.html#method.refresh_token) —
в ответе он обычно меняется, так что записывать надо новый.

## загрузки

путей два, и они **не** взаимозаменяемы.

| | `track_download_info` | `track_lossless_info` |
|---|---|---|
| кодеки | mp3, aac | flac, flac-mp4, aac, mp3 |
| эндпоинт | `/tracks/{id}/download-info` | `/get-file-info` (с подписью) |
| время жизни ссылки | ~1 минута, достаётся из xml-документа | зеркала, живут дольше |
| шифрование | нет | aes-ctr (`transport: encraw`) |

нужен вам обычно lossless-путь, и `Downloader` расшифровывает поток на лету, так что
flac на 300 мб никогда не оказывается в памяти целиком:

```rust,no_run
# #[cfg(feature = "download")]
# async fn run(client: &yamuse::Client) -> Result<(), yamuse::Error> {
use yamuse::download::{Downloader, Strategy};

let info = client.track_lossless_info(42, "lossless").await?;
if !info.is_lossless() {
    eprintln!("flac-источника нет; api откатился на {:?}", info.codec);
}

Downloader::new(client.transport(), info.links())
    .maybe_encraw_key(info.key.clone())
    .strategy(Strategy::Race) // открыть все зеркала, оставить самое быстрое
    .to_file("track.flac")
    .await?;
# Ok(())
# }
```

## realtime — что играет прямо сейчас

ynison — единственный канал, по которому яндекс музыка сама шлёт события; вебхуков
нет. `Realtime` берёт на себя рукопожатие, keepalive и переподключение:

```rust,no_run
# #[cfg(feature = "realtime")]
# async fn run() -> Result<(), yamuse::Error> {
use yamuse::ynison::{Event, Realtime, RealtimeConfig};

let realtime = Realtime::start(RealtimeConfig::new("your-token"));
let mut events = realtime.subscribe();

while let Ok(event) = events.recv().await {
    match event {
        Event::TrackChanged(id) => println!("сейчас играет: {id}"),
        Event::PauseChanged(paused) => println!("{}", if paused { "пауза" } else { "играет" }),
        Event::Closed => break,
        _ => {}
    }
}
# Ok(())
# }
```

`realtime.now_playing()` отвечает синхронно по последнему кадру, экстраполируя
позицию на момент вызова — удобно, когда надо обслужить http-запрос, не дожидаясь
следующего обновления.

## ошибки

всё сходится в один enum [`Error`], так что один `match` покрывает всю поверхность:

```rust,no_run
# async fn run(client: &yamuse::Client) -> Result<(), yamuse::Error> {
use yamuse::Error;

match client.track(42).await {
    Ok(track) => println!("{track:?}"),
    // токен истёк или не был валидным
    Err(Error::Unauthorized(_)) => {}
    // api ограничивает; `retry_after()` скажет насколько, если сервер сказал
    Err(Error::RateLimited { retry_after, .. }) => println!("ждём {retry_after:?}"),
    Err(err) if err.is_retryable() => println!("временная: {err}"),
    Err(err) => return Err(err),
}
# Ok(())
# }
```

`is_retryable()` истинно для транспортных сбоев, 5xx и 429. идемпотентные `GET`
повторяются внутри сами, так что если такая ошибка дошла до вас — попытки кончились.

[`Error`]: https://docs.rs/yamuse/latest/yamuse/error/enum.Error.html

## что покрыто

все эндпоинты api, сгруппированные так же, как методы клиента:

| группа | эндпоинты |
|---|---|
| **аккаунт** | статус, настройки (чтение и запись), офферы покупки, алерты о правах, эксперименты, промокоды |
| **треки** | пакетная выборка, lossy-загрузка, lossless (flac), тексты (обычный и lrc), похожие, полная информация, трейлер, дополнения, отчёт о проигрывании, шоты после трека |
| **альбомы** | пакетная выборка, с треками, похожие сущности, трейлер |
| **артисты** | пакетная выборка, краткая информация, треки, альбомы (свои / участие / дискография / safe-direct), похожие, ссылки, трейлер, id треков, информация, о себе, клипы, донаты, скелеты |
| **плейлисты** | чтение, создание, удаление, переименование, видимость, описание, правки через diff, вход в совместный, по uuid, персональные (дня и прочие), трейлер, kinds, похожие сущности |
| **лайки** | лайк и дизлайк треков, артистов, альбомов, плейлистов и клипов; чтение всех библиотек |
| **поиск** | полный поиск по всем типам, подсказки |
| **радио** | дашборд, список станций, информация о станции, пачки треков, все четыре события фидбэка, настройки станции |
| **лендинг** | блоки лендинга, чарты, новые релизы, новые плейлисты, подкасты, жанры, фид, состояние визарда, теги |
| **история** | история прослушиваний по дням, разрешение элементов |
| **очереди** | список, чтение, создание, обновление позиции |
| **метатеги** | навигационные деревья, детали метатега, альбомы, артисты, плейлисты |
| **концерты** | концерты артиста, информация о концерте, фид, локации, конфиг вкладок, скелеты |
| **клипы** | пакетная выборка, рекомендации |
| **пины** | список, закрепить и открепить альбомы, артистов, плейлисты, волны |
| **пресейвы** | список, добавление, удаление |

| **кредиты** | производственные кредиты треков и клипов |
| **дисклеймеры** | дисклеймеры треков, клипов, альбомов и артистов |
| **device auth** | запрос кода, поллинг, обновление, полный блокирующий флоу |
| **realtime** | состояние плеера ynison с переподключением |

## флаги фич

| флаг | по умолчанию | что добавляет |
|---|---|---|
| `rustls-tls` | да | tls через rustls |
| `native-tls` | нет | tls через системную библиотеку |
| `download` | да | потоковая загрузка на диск |
| `realtime` | нет | поток состояния плеера ynison |
| `tracing` | нет | события `tracing` для запросов, повторов, лимитов и переподключений |
| `full` | нет | `download` + `realtime` + `tracing` |

## решения в дизайне

**устойчивость к приватному api.** это обёртка над api, который меняется без
предупреждения, поэтому каждый слой деградирует, а не ломается:

- поле, которое api *перестал слать*, становится `None` — все поля моделей
  опциональны.
- поле, которое api *начал слать*, игнорируется, а не роняет разбор.
- поле, у которого *сменился тип*, стоит вам этого поля, а не всего запроса.
  json-float на месте целого сужается; всё остальное отбрасывается, и вам об этом
  сообщают через `on_field_repair`. это не гипотетика: `Status.hasOptions` по
  одному своему имени читается как булево, а приходит списком.
- полиморфная нагрузка с неизвестным `type` сохраняется как сырой json
  (`SearchEntity::Unknown`, `BlockEntityData::Unknown`), а не выбрасывается — одна
  незнакомая плитка не должна ронять весь лендинг.

```rust,no_run
# fn main() -> Result<(), yamuse::Error> {
let client = yamuse::Client::builder()
    .token("token")
    // сужение float ничего не теряет; is_lossy() отфильтрует настоящий дрейф
    .on_field_repair(|repair| {
        if repair.is_lossy() {
            eprintln!("дрейф api: {repair}");
        }
    })
    .build()?;
# Ok(())
# }
```

**повторы только там, где это безопасно.** идемпотентные `GET` повторяют временные
сбои с экспоненциальной задержкой и полным джиттером. мутации получают ровно одну
попытку: повторённый `playlists/create` создаст два плейлиста. детерминированные
отказы (400, 404, 409, 413) тоже не повторяются — они падают одинаково всегда.

429 — исключение среди 4xx: «слишком часто» означает «не сейчас», а не «никогда».
`retry-after` из ответа выжидается дословно, без джиттера, но с потолком
`RetryPolicy::retry_after_max` — этот api реально отвечает задержками в час, и
честное их соблюдение заблокировало бы вызов до конца дня.

**на диск не попадает ничего недописанного.** загрузка идёт в соседний файл `.part`
и переименовывается на место только после завершения, так что в точке назначения
либо целый трек, либо ровно то, что там было. это закрывает и сорвавшуюся передачу,
и процесс, убитый на середине: обрезанный трек выглядит как валидный кэш, а это хуже
явной ошибки.

**типизированные параметры.** то, что api принимает голыми строками, здесь настоящие
enum'ы (`SearchType`, `LyricsFormat`, `MoodEnergy`, …), так что опечатка — ошибка
компиляции, а не загадочный 400. всё, что попадает в путь url, percent-кодируется,
поэтому `/` внутри uuid плейлиста не может увести запрос на другой эндпоинт.

**несостоявшаяся мутация — это ошибка.** каждый мутирующий метод возвращает
`Mutation`, а не `bool`. булево могло сказать только «не сработало» — без причины и
молча, потому что возвращённый `bool` никто не проверяет. `Mutation` заодно приносит
`revision` библиотеки от тех двух эндпоинтов, которые его сообщают.

**длинные списки id разбиваются.** библиотека из нескольких тысяч лайкнутых треков
иначе была бы одним запросом, который api отвергает целиком. пакетные чтения режутся
прозрачно; пакетные мутации тоже режутся, и это отдельно оговорено — падение на
середине оставляет ранние части применёнными.

**дешёвое клонирование.** `Client` реализует `Clone` и разделяет один пул соединений
и один кэш аккаунта; передавайте клоны, а не заворачивайте в ещё один `Arc`.

## примеры

| пример | что показывает |
|---|---|
| `search` | самый короткий полезный вызов, с подключённым отчётом о дрейфе |
| `library` | лайкнутые треки, альбомы и артисты |
| `playlist` | создание и правка — и почему без `revision` не обойтись |
| `lyrics` | эндпоинт с подписью и ответ, в котором ссылка, а не слова |
| `radio` | станция ротора с фидбэком, который шлёт настоящий плеер |
| `download` | потоковая загрузка lossless на диск с расшифровкой на лету |
| `now_playing` | поток ynison |
| `device_auth` | получение токена без встроенного браузера |
| `drift` | что api присылает, а крейт ещё не моделирует |

```bash
YM_TOKEN=... cargo run --example search
YM_TOKEN=... cargo run --example playlist        # пишет в аккаунт
YM_TOKEN=... cargo run --example drift
YM_TOKEN=... cargo run --example download --features download
YM_TOKEN=... cargo run --example now_playing --features realtime
cargo run --example device_auth
```

## правовая заметка

здесь используется приватное api, а не опубликованное. oauth-креды по умолчанию —
креды android-приложения яндекс музыки, извлечённые из общедоступного apk; запросы с
ними выглядят как запросы этого приложения. так устроен любой сторонний клиент к
этому сервису, и яндексом это не одобрено. проверьте условия использования, прежде
чем что-либо на этом разворачивать.
